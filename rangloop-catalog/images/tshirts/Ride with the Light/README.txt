HOW TO ADD IMAGES FOR THIS T-SHIRT (tshirt-01)
====================================================
Drop your image files into the matching colour subfolder.

  tshirt-01/
    black/    <-- black colour images here  (e.g. front.jpg, back.jpg)
    white/    <-- white colour images
    red/      <-- red colour images
    blue/     <-- blue colour images
    green/    <-- green colour images
    yellow/   <-- yellow colour images
    navy/     <-- navy colour images
    grey/     <-- grey colour images
    maroon/   <-- maroon colour images
    orange/   <-- orange colour images

RECOMMENDED NAMING
  front.jpg  = main / front view
  back.jpg   = back view
  side.jpg   = side / detail view

After adding images, update js/products.js to list the file paths
under the matching colour entry for this t-shirt.
