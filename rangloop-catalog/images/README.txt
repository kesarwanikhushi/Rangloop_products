Add your product images here.

Naming convention:
  productN-front.jpg   (N = product id number)
  productN-back.jpg
  productN-side.jpg

Rules:
  - All lowercase filenames
  - No spaces — use hyphens instead
  - Supported formats: .jpg  .jpeg  .png  .webp
  - Recommended size: 800×1067px (3:4 ratio, portrait)
  - Keep file sizes under 300 KB for fast mobile loading
    (use https://squoosh.app to compress for free)

Then reference the filename in js/products.js like:
  "images/product3-front.jpg"
